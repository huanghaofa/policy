# 策源 · 全国政策观察 V1

面向工信、商务和政府投资基金领域的政策信息看板。

访问地址：https://huanghaofa.github.io/policy/

当前发布为第一版静态快照，包含 1180 条来自官方公开页面的政策与通知线索。数据采集截止时间：2026-10-26T23:22:52+08:00。

支持地区、领域、内容类型、时间和关键词筛选，以及浏览器收藏、CSV 导出和官方原文跳转。收藏仅保存在当前浏览器。

来源配置涵盖大陆 31 个省级地区和 35 个城市的部分来源，不代表全国所有市县、所有栏目或全部政策。来源可访问、识别政策、未识别到政策和访问受限分别记录。

发布日期来自官方页面或列表，未核实的日期显示“日期待核”。地区与分类按标题和来源辅助识别；文件有效性、适用范围、申报条件与截止日期以官方原文为准。

本仓库仅提供静态浏览版本。站内“刷新页面”重新加载当前发布的快照，不会发起政策采集。

通过 GitHub Pages 从 `main` 分支根目录发布，无需构建或第三方运行依赖。
